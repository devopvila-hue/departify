# Supabase

Supabase is the official data platform for Departify.

This Golden Image only prepares local Supabase CLI configuration. It does not create tables, migrations, Auth configuration, Storage buckets, Edge Functions, seeds, RLS policies, or product data.

## Commands

```sh
pnpm exec supabase start
pnpm exec supabase status
pnpm exec supabase stop
```

The CLI requires a Docker-compatible runtime.
