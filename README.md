# Departify V2

Departify V2 is a SaaS AI-first multi-company platform.

This repository is currently in Sprint 1 bootstrap state. It contains the monorepo structure, package boundaries, base tooling, and minimum documentation required to begin controlled product development.

No business functionality, legacy migration, API, portal, backend, database, LLM router, RAG, memory, plugins, or n8n workflows are implemented in this sprint.
