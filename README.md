# Departify V2

Departify V2 is a SaaS AI-first multi-company platform.

This repository is currently in Sprint 3 foundation state. It contains the monorepo structure, package boundaries, base tooling, minimum documentation, initial portal runtime infrastructure, and initial backend runtime infrastructure required to begin controlled product development.

No business functionality, legacy migration, authentication, database, LLM router, RAG, memory, plugins, or n8n workflows are implemented in this sprint.
