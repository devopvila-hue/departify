# Portal

Independent user-facing portal application boundary.

Sprint 2 initializes the portal runtime only:

- Vite application shell.
- React entrypoint.
- Router boundary.
- Provider composition boundary.
- Base styling tokens.
- Unit test harness.

It intentionally contains no product pages, authentication flow, API integration, database access, LLM routing, RAG, memory, plugins, workflows, or migrated legacy functionality.
