# AI Guidelines

## Required behavior

- Read local context before making changes.
- Preserve existing user work.
- Keep changes scoped to the task.
- Validate changes proportionally to risk.
- Commit using Conventional Commits.
- Push before reporting sprint completion.
- Report assumptions and validation results.

## Safety rules

- Do not expose secrets or credentials.
- Do not perform destructive actions without explicit authorization.
- Do not invent project facts.
